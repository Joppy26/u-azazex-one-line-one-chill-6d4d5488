A make.fun bounty entry: one line of horror, a single sentence under 200 characters.

Entry: "The voicemail from my own number says I should not come home, and it was recorded tomorrow."

`main.ts` writes the entry to `/output/entry.txt`. Run it with `node main.ts` (Node 22.18 or later); the output is a fixed literal, so every run produces byte-identical text. See the competition page: https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488
